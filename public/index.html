Prompt #3 — Facebook Ad Copy Generator
You are an expert D2C copywriter specializing in the Indian market. Write 3 variations of a Facebook ad for the following product: Product: [Product Name] Price: ₹[Price] Target Audience: [e.g., women aged 25-35 in metro cities] Key Benefit: [e.g., organic ingredients, fast delivery] Offer: [e.g., 30% off, free shipping, buy 1 get 1] Tone: [e.g., casual & friendly / premium / urgent] For each variation, write: 1. A scroll-stopping headline (under 8 words) 2. Primary text (under 125 words) — use storytelling + urgency 3. A clear CTA line Rules: - Include at least 1 Hindi phrase naturally (e.g., "ab bas karo guessing") - Use price anchoring (compare to higher alternatives) - Reference Indian context (festivals, weather, metro life) - Add 2-3 relevant emojis per variation
💡 Pro Tip: Run this prompt 3 times and pick the best headline from each batch. Test 3 headlines against each other in your Facebook ad set for maximum CTR.
Prompt #1 — Property Listing Description Writer
You are a premium real estate copywriter for the Indian property market. Write a compelling listing description for: Property Type: [e.g., 3BHK Flat / Independent Villa / Commercial Space] Location: [e.g., Whitefield, Bangalore] Area: [e.g., 1,450 sq ft carpet] Price: ₹[Price] Key Features: [e.g., modular kitchen, 2 balconies, gated community, gym] Nearby Landmarks: [e.g., 5 min from Phoenix Mall, near metro station] Target Buyer: [e.g., IT professionals, NRIs, families] Write: 1. A headline that creates desire (not just "3BHK for sale") 2. A 150-word emotional description (paint a lifestyle picture) 3. Bullet-point feature highlights (8-10 items) 4. A closing CTA with urgency Optimize for: 99acres, MagicBricks, and Housing.com search visibility. Include relevant locality keywords naturally.
💡 Pro Tip: After generating, paste the output into the "Description" field of 99acres/MagicBricks. Properties with detailed, emotional descriptions get 3x more inquiries than one-liners.
Prompt #5 — 30-Day Instagram Content Calendar
You are a social media strategist for Indian creators. Create a complete 30-day Instagram content calendar for: Niche: [e.g., personal finance / fitness / tech reviews / cooking] Target Audience: [e.g., college students in India aged 18-25] Goals: [e.g., grow followers, drive course sales, build authority] Content Mix: Reels (60%), Carousels (25%), Stories (15%) For each of the 30 days, provide: - Day number and day of week - Content type (Reel / Carousel / Story) - Topic and hook line (first line people see) - Brief content outline (3-4 bullet points) - Hashtag set (10 hashtags — mix of big + niche) - Best posting time for Indian audience Rules: - Include trending Indian topics and cultural references - Add 2 "engagement bait" posts (polls, questions) - Include 4 "save-worthy" educational posts - Add 2 collaboration/duet ideas - Mark festival-related content opportunities
💡 Pro Tip: Use this as your master plan, then use Prompt #6 (Reel Script Writer) and Prompt #8 (Carousel Builder) to flesh out each day's content in full detail.
Prompt #1 — ATS Resume Rewriter
You are an expert resume consultant who specializes in ATS (Applicant Tracking System) optimization for the Indian job market. Rewrite my resume for this specific job: My Current Resume/Experience: [Paste your current resume text here] Target Job Title: [e.g., Senior Software Engineer] Target Company: [e.g., Flipkart / Infosys / a Series B startup] Job Description Keywords: [Paste the job description here] Rewrite rules: 1. Extract top 15 keywords from the job description and weave them naturally 2. Rewrite each bullet point using the XYZ formula: "Accomplished [X] as measured by [Y] by doing [Z]" 3. Quantify every achievement (add numbers, percentages, ₹ values) 4. Keep it to 1 page for <8 years experience, 2 pages for 8+ years 5. Use professional Indian English (not American spellings) 6. Highlight any relevant certifications or projects 7. Add a powerful 2-line professional summary at the top Output the complete rewritten resume in a clean, copy-paste format.
💡 Pro Tip: After rewriting, paste your new resume into a free ATS checker like Jobscan or Resume Worded to verify it scores 80%+ match against your target job description.
